About

What is openmusic?

openmusic

v1.0.0

A beautifully minimal English music player. Stream, like, queue, and download tracks — all in one clean interface with no distractions.

Features
Stream High-quality audio up to 320 kbps via JioSaavn.
Like Save your favourite tracks locally, always available.
Queue Build a play queue on the fly, shuffle anytime.
Download Download any track directly to your device.
Playlists Create and manage multiple playlists locally.
Dark mode Easy on the eyes at any hour.
Tech Stack
FrontendVanilla HTML · CSS · JavaScript
APIJioSaavn unofficial API
IconsLucide Icons
FontsInter · DM Mono (Google Fonts)
StoragelocalStorage (likes, playlists, recent)
Disclaimer
This project is for personal and educational use only. All music content is streamed from JioSaavn and remains the property of the respective rights holders.
